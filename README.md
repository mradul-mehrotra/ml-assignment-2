# Online Shopper Purchase Intention — Classification Assignment

## a. Problem statement

The objective is to predict whether an online shopping session will result in a purchase (`Revenue`). Five supervised classification algorithms are trained and compared using the same stratified hold-out test set. A Streamlit application loads the saved pipelines and evaluates uploaded labelled test data without retraining.

## b. Dataset description

- **Dataset:** Online Shoppers Purchasing Intention
- **Source:** UCI Machine Learning Repository
- **URL:** https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset
- **Target:** `Revenue` (0 = no purchase, 1 = purchase)
- **Original dataset:** 12,330 sessions and 17 input features.
- **Task:** Binary classification.

Download the CSV from UCI and place it at `data/online_shoppers_intention.csv`. Do not commit the full training dataset unless your instructor specifically requests it.

## How to run locally or in BITS Virtual Lab

1. Download the UCI CSV and place it at `data/online_shoppers_intention.csv`.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Train and evaluate all five models:

   ```run
   models.ipynb
   ```

4. Start the Streamlit app:

   ```bash
   streamlit run app.py
   ```

5. Upload the generated `test_data.csv` in the app. It contains the held-out test features and the `Revenue` target. The app evaluates saved models; it does not retrain them.

## Streamlit application features

- Model selection dropdown.
- Accuracy, AUC, Precision, Recall, F1 and MCC.
- Confusion matrix.
